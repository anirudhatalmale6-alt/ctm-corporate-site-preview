# CTM Professional Services — corporate site (preview build)

A five-page static corporate website built for CTM Professional Services
PTY. LTD., using CTM's own copy and brand colours, in the visual register of
dxc.com.

Live preview: see the GitHub Pages link on this repository.

- Pages: Home, About Us, Services, Insights, Contact Us
- No framework, no build step, no database — upload and it runs
- ~53 KB over the wire, 5 requests, zero third-party calls
- `contact.php` included for the working contact form
- `HANDOFF.md` explains how to edit everything without a developer

Built by Anirudha Talmale.
